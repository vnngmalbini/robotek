import quarky

import cv2, time

from pictoblox import AI_Vision


robot = quarky.Quarky()

robot.led_matrix.show_face("HAPPY")

vision = AI_Vision.FaceDetection()


if vision.detect_face():

    robot.speaker.play_greeting("Welcome Innovator!")

    robot.motors.forward(speed=80, duration=2)

Nurturing Tomorrow's Innovators & Problem Solvers

RoboTek is dedicated to bringing this proven, world-class ecosystem across Africa, bridging the practical technology gap and preparing students for the 21st-century technological economy.
